## Running

从工作区根目录直接运行文件；同目录导入使用新的英文模块名。例如：

```bash
/home/hatepp/miniconda3/envs/piper/bin/python first_step/actor-critic/lesson_19_gae_actor_critic.py
```

跨目录导入需要明确设置 Python 搜索路径。目录名不是 Python 包名；上面的方式以直接运行脚本为准。
