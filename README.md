# 从零开始的强化学习学习记录

之前主要是跟着教程理解、手敲代码。现在希望逐步弄清楚每一步为什么这样写，练习自己设计、实现和验证，并且能解释程序的行为和实验结果。

目前还在补 Python、PyTorch 和相关数学基础，主要练习张量形状与广播、自动求导、参数更新、简单神经网络，以及概率分布和动作采样。同时也在学习代码结构、命名规范、调试和测试，希望慢慢养成规范编程、读懂代码和分析错误的习惯。

- [强化学习指南.txt](强化学习指南.txt)：长期学习路线和阶段验收要求，会根据实际学习情况调整。
