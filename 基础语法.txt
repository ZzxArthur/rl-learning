| 场景 | 选择 | 原因 |
| --- | --- | --- |
| 把每批形状 `(6,)` 的梯度组成 `(200, 6)` | `stack` | 新增“批次”维度 |
| 把多个形状 `(2,)` 的状态组成 `(T, 2)` | `stack` | 新增“时间步”维度 |
| 把两局形状 `(2, 2)`、`(1, 2)` 的状态拼成 `(3, 2)` | `cat` | 时间步维度已存在，沿它继续拼接 |
| 把权重梯度 `(4,)` 和偏置梯度 `(2,)` 拼成 `(6,)` | `cat` | 只需要一条完整梯度向量 |
import torch

a = torch.tensor([1, 2])
b = torch.tensor([3, 4])

torch.cat([a, b], dim=0)
# tensor([1, 2, 3, 4])      shape: (4,)

torch.stack([a, b], dim=0)
# tensor([[1, 2],
#         [3, 4]])          shape: (2, 2)
